## 🏋️‍♂️ FitLog Workout Library

FitLog is a modern, responsive web application designed to help users track their workout plans, organize daily fitness routines, and manage saved exercises effortlessly.

---

## 🛠️ Technologies Used

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** React Context API (Global State)
- **Icons:** Lucide React
- **Notifications:** React Toastify
- **Storage:** LocalStorage API

---

## ✨ Key Features

1. **Global State Management:** Powered by React Context API to seamlessly share workout data and application state across all components without prop drilling.
2. **Daily Plan Management:** Add, complete (Mark as Done), or remove exercises specifically tailored for today's routine.
3. **Saved Workouts Library:** Bookmark favorite workouts into a dedicated "Saved" section for quick access anytime.
4. **Interactive Sorting:** Easily sort your workouts by duration, calories burned, or rating to find the right exercise faster.
5. **Real-time Stat Tracker:** Dynamic overview showing total exercises, total duration (minutes), and total calories burned.
6. **Persistent Local Storage:** Synchronizes data instantly with `localStorage` and custom events so your plan stays updated across tabs without a page reload.
